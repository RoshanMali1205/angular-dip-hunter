# Email templates

Paste each file into **Supabase → Authentication → Email Templates**.

| Dashboard name | File |
|----------------|------|
| Confirm signup | `confirm-signup.html` |
| Reset password | `reset-password.html` |
| Magic Link | `magic-link.html` (optional) |

Also set:

1. **Authentication → Providers → Email** → Confirm email **ON**
2. **Authentication → URL Configuration**
   - Site URL: `https://YOUR-NETLIFY-SITE.netlify.app`
   - Redirect URLs: that origin, `https://YOUR-NETLIFY-SITE.netlify.app/auth/callback`, `http://localhost:4200/**`
3. Sender name: `Dip Hunter`

Do not put secrets in these HTML files. The `{{ .ConfirmationURL }}` value is generated by Supabase.
